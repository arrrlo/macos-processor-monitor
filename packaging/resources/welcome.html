macOS Processor Monitor

A lightweight menu bar monitor for Apple Silicon processors. It shows processor load and temperature in the menu bar, and the full picture in its menu and dashboard:

  • overall load with the user / system / idle split
  • occupancy of every core, grouped by core cluster
  • processor temperature
  • the 10 processes using the most processor time

This installs:

  • macOS Processor Monitor.app in Applications
  • a small helper that measures every process's CPU usage (macOS only shows other users' processes to administrators). It is read-only, starts only while the menu or dashboard is open, and quits 30 seconds after.
  • a login item, so the monitor starts when you log in. You can turn it off from the menu.
